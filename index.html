Microphone prompt did not appear? Tap here for help
  1. Chrome on a computer: click the site controls icon to the left of the web address, open Site settings, set Microphone to Allow, then reload this recorder tab.
  2. Chrome on Android: tap the icon to the left of the web address, open site permissions, allow the microphone, then reload this tab.
  3. Safari on iPhone/iPad: open this link in Safari, tap the aA or page menu, open Website Settings, and allow microphone access. Also check the device's Settings if needed.
  4. Make sure the device has a microphone and that another app is not exclusively using it.

If the microphone is already set to Allow, reload this tab and press Start recording again.
